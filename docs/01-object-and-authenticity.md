# 01. Объект исследования и форензика подлинности

> **Объект:** `game_scarlett_master.exe` — исполняемый файл консольной сборки
> **Grand Theft Auto VI (GTA VI / GTA 6)** для Xbox Series X|S, версия 1.0.2.1.
> Источник — утечка **GTA6.Xbox.v1.0.2.1-CYBERLEEK**.

## Идентификация образца

| Свойство | Значение |
|---|---|
| Размер | 120 181 760 байт (114,6 МБ) |
| Формат | PE32+ (AMD64), подсистема WINDOWS_GUI |
| База образа | 0x140000000, виртуальный размер ~176 МБ |
| TimeDateStamp | 2026-11-13 21:40:36 UTC (за 6 дней до релиза GTA VI на консолях 19.11.2026) |
| SHA-256 | `e95020b2fa4a721db3df59fdecf75621730ac559d8835252f6c3b658d5a08993` |
| SHA-1 | `2be54b5e91275a2a8a0ba65b74eab51527933522` |
| MD5 | `8609e31e0b9a2192b3f80771d16ca32c` |
| CRC32 | 0x77990538 (совпадает с метаданными 7z-контейнера) |

Файл распространялся как трёхтомный 7z-архив (режим store, без сжатия).
При неполной загрузке томов контейнер не распаковывается — отсюда жалобы
на «битый» файл. Все три тома, распаковка прошла без ошибок, единственная
запись внутри — сам exe.

## Методика

Только статический анализ:

- разбор PE-структуры (pefile);
- извлечение и классификация ASCII/UTF-16 строк;
- разбор таблиц импорта/экспорта, RTTI-дескрипторов, каталога отладки;
- анализ секции исключений `.pdata` и дизассемблирование точки входа (Capstone x86-64);
- OSINT-сверка: публикации, файл-листы утечки, diff-отчёты сообщества, отчёт публичной песочницы.

Образец **не запускался** в исполняемой среде — и по соображениям
безопасности, и потому что он в принципе не предназначен для выполнения
под Windows.

## Признаки подлинности

Вердикт: все наблюдаемые признаки **согласуются с заявленным происхождением**
(абсолютного доказательства в виде Authenticode-подписи нет по природе
объекта — консольные GXDK-сборки не подписываются, подпись несут пакеты XVC):

- PDB-путь в каталоге отладки: проект `americas` (официально подтверждённое
  кодовое имя GTA VI — Project Americas), ветка `sub_story`, платформа
  `Gaming.Xbox.Scarlett.x64` (штатное имя MSBuild-платформы Xbox Series X|S
  в GDK), конфигурация `master`. Соглашение об именах Rockstar:
  `game_<платформа>_<конфигурация>.exe` (в эпоху Xbox One — `game_durango_master.exe`).
- Компилятор — внутренний форк LLVM Rockstar (RSG-LLVM 19.1.7); линкер lld-link
  (Rich-заголовок отсутствует — атрибут LLVM-семейства).
- URL-протокол запуска сюжетного контента `americas://…`.
- Полный набор консольных зависимостей Xbox Series в import-таблице.
- Экспорт `__XMemAllocationHooks__` — характерный маркер Xbox-инструментирования памяти.
- Секции `.retplne` (маркеры retpoline / защита Spectre), `.voltbl`
  (энергоменеджмент), `.xbld` (метаданные GDK/GDKX) — консольная специфика.
- Отпечаток сборки согласуется с версией 1.0.2.1 и датой NOV 2026.

## Чего НЕ найдено

- Вредоносного кода, упаковщиков, Denuvo.
- Маркеров других игр (GTA V, RDR2, Steam/Epic).
- Отчёт публичной песочницы по идентичному образцу: низкие статическая и
  поведенческая оценки, без отнесения к семействам малвари.

## Структура секций

| Секция | RAW, байт | Энтропия | Назначение |
|---|---|---|---|
| .text | 99 875 328 | 6.754 | Код, ~95 МБ, без упаковки |
| .rdata | 9 047 552 | 5.896 | Константы, RTTI, строки |
| .data | 6 434 304 | 2.376 | Данные (виртуальный размер 71,2 МБ, большой BSS) |
| .pdata | 3 591 168 | 6.876 | **299 257 функций** (unwind-записи x64) |
| .retplne | 512 | 1.638 | Маркеры retpoline (Spectre) |
| .tls | 5 632 | 0.166 | TLS-блок и колбэки |
| .voltbl | 2 048 | 5.933 | Voltage-таблицы |
| .xbld | 2 048 | 4.541 | Метаданные GDK/GDKX |
| .reloc | 1 221 632 | 5.636 | ~600 тыс. записей перемещений |

Практический вывод: файл исправен и целостен, но запустить его вне Xbox
Series нельзя — он ссылается на системные модули консоли, публичного
эмулятора Series X не существует, а в утечке были только исполняемые файлы
без игровых ресурсов.

⚠️ Важно: вокруг утечки действуют мемкоин-схемы, а в сети распространяются
вредоносные подделки под этот файл — сверяйте хэши.
